# NEON GLIDE 안드로이드 베타 테스터 모집 문구

목적은 홍보가 아니라 **Google Play 프로덕션 액세스 조건 충족**이다.

| 조건 | 현재 |
|---|---|
| 비공개 테스트 버전 게시 | 완료 (버전 2 / 1.0.1, targetSdk 36) |
| 테스터 **12명 이상**이 참여를 선택 | **0명** |
| 그 12명 대상 **14일 이상 연속** 테스트 | 미시작 |

그래서 문구의 목표는 "재밌어 보이죠?"가 아니라 **"링크 누르고, 설치하고, 2주간 지우지 말아 주세요"** 라는
구체적인 부탁을 상대가 부담 없이 받아들이게 만드는 것이다. 숫자와 소요 시간을 먼저 밝힌다.

필요한 링크 두 개:

- **옵트인 링크** — Play Console → NEON GLIDE → 테스트 → 비공개 테스트 → 테스터 탭 하단
  "참여 링크 복사". 아래 문구의 `<옵트인_링크>`를 전부 이걸로 치환한다.
- **웹 버전** — https://neon.habitschool.kr/ (설치 없이 먼저 해보게 하는 용도)

주의: 테스터 구매·봇 설치는 계정 정지 사유다. 실제로 켜보는 사람 12명을 모으는 게 결국 빠르다.

## 1. 게임 사이트 배너 — 전환이 가장 좋다

이미 게임을 해본 사람에게 묻는 것이라 수락률이 가장 높다. 시작 화면 하단에 한 줄.

**짧은 버전**
```
📱 안드로이드 베타 테스터를 찾습니다 — 12명만. 2주간 설치만 유지해 주시면 됩니다.
```

**눌렀을 때 뜨는 안내**
```
NEON GLIDE를 Google Play에 정식 출시하려면, 구글이 "테스터 12명이 2주 이상
설치한 상태"를 요구합니다. 지금 11자리가 비어 있습니다.

하실 일은 세 가지입니다.
1. 아래 링크를 안드로이드 폰에서 열고 '테스터 되기'를 누릅니다
2. Play 스토어에서 NEON GLIDE를 설치합니다
3. 2주 동안 지우지 않습니다 (가끔 한 판 해주시면 더 좋고요)

광고 없고 결제 없고 계정 가입도 없습니다. 웹에서 하던 그 게임 그대로입니다.
2주 뒤에는 지우셔도 됩니다.

<옵트인_링크>
```

## 3. 한국 커뮤니티 — 인디게임 / 안드로이드 게시판

디시 인디게임 갤러리, 루리웹 인디게임 게시판, 네이버 안드로이드 관련 카페, 개발자 오픈카톡방.
"품앗이"가 통용되는 곳에서는 상호 테스트를 제안하는 쪽이 훨씬 빠르다.

**제목**
```
[테스터 품앗이] 매일 전 세계가 같은 코스를 도는 원버튼 게임, 12/14 채우는 중입니다
```

**본문**
```
개인 개발로 만든 NEON GLIDE입니다. 비공개 테스트 12명 × 14일 조건을 채우는 중이라
테스터를 찾습니다. 품앗이 환영합니다 — 알려주시면 저도 바로 설치하고 2주 유지합니다.

게임은 이렇습니다.
- 버튼 하나. 누르면 상승, 떼면 하강. 그게 조작의 전부입니다.
- 코스가 날짜 시드로 생성돼서, 오늘 서울에서 도는 코스와 상파울루에서 도는 코스가
  완전히 같습니다. 운이 아니라 실력만 비교됩니다.
- 하루 세 번의 완주(26게이트 → 50게이트 → 40게이트). 하나 끝내야 다음이 열립니다.
- 그냥 통과하면 점수가 거의 안 붙습니다. 가장자리를 스치고 레이저를 뚫어야
  체인이 쌓이고 배율이 ×10까지 올라갑니다.
- 광고 없음, 인앱결제 없음, 계정 가입 없음. 하루치가 3분쯤 걸립니다.

웹으로 먼저 해보실 수 있습니다: https://neon.habitschool.kr/
테스터 참여: <옵트인_링크>

설치하신 분은 댓글이나 쪽지 주세요. 바로 품앗이 가겠습니다.
```

## 5. 설치해 준 사람에게 보낼 안내 — 14일을 실제로 지키게 하는 문구

조건이 깨지는 가장 흔한 이유는 "설치했다가 며칠 뒤 지움"이다. 수락 직후에 보낸다.

```
설치해 주셔서 감사합니다! 조건을 채우려면 한 가지만 부탁드립니다.

👉 12월 N일까지는 지우지 말아 주세요.
   중간에 지우면 그 사람 몫의 카운트가 빠지고, 14일이 처음부터 다시 셉니다.

하루에 한 번 열어서 한 판만 해주시면 구글 심사에도 유리합니다.
(코스가 매일 바뀌어서 어제 한 사람도 오늘 새로 할 게 있습니다)

버그나 이상한 점 있으면 편하게 알려주세요. 그게 테스트의 본래 목적이기도 하고요.
```

날짜(`12월 N일`)는 12명이 다 모인 날 + 14일로 계산해서 채워 넣는다. 카운트가 12명이 된 날부터
세기 시작하므로, 12번째 사람이 들어온 날짜를 기록해 둘 것.
